如何从零搭建并部署一个网站

首页 Computer Science

本文记录从零开始搭建并部署一个网站的完整流程。以 Python 网站为例，使用 Codex 生成网站代码，通过云服务器部署网站，使用域名访问，最后通过 Nginx 配置反向代理，并使用 Let’s Encrypt 提供的 Certbot 配置 HTTPS。

整个流程可以分为四个阶段：

  1. 创建网站：使用 Codex 生成网站代码及相关资源。
  2. 购买服务器：准备运行环境，安装 Python、Nginx 等软件。
  3. 购买域名：配置 DNS 解析，申请 SSL/TLS 证书。
  4. 网站部署：上传网站文件，配置 Nginx，启动服务并验证网站。

# 购买服务器

网站代码准备完成后，需要购买一台云服务器，用于部署和运行网站。

# 选择服务器

常见的云服务器提供商：

  • 阿里云：国内服务器，适合面向国内用户的网站。
  • 搬瓦工（BandwagonHost）：海外 VPS，适合部署面向海外用户的网站。
  • 其他选择：腾讯云、华为云、AWS、DigitalOcean 等。

对于简单的个人博客或展示型网站，通常可以从 1 核 CPU、1GB～2GB 内存的服务器开始。

# 配置 Nginx 反向代理

Nginx 是一个高性能 Web 服务器，也可以作为反向代理服务器使用。

它在本次部署中的主要作用是：

  1. 接收用户发起的 HTTP/HTTPS 请求。
  2. 根据域名匹配对应的网站配置。
  3. 将请求转发到本机运行的 Python 服务。
  4. 将 Python 服务返回的内容转发给用户。

这样，Python 服务只需要监听本机的 8000 端口，无需直接暴露给公网。
